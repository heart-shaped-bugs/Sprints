# Тест-план: detect_prey_by_electric_field

## 1. Область тестирования

**Функция:**  
`detect_prey_by_electric_field(depth_cm: float) -> dict`

**Что проверяется:**

- Возврат структуры `{"detected": bool, "prey_type": str, "distance_mm": float}`  
- Правильность расчёта вероятности обнаружения (`min(1.0, electroreceptor_count / 2000)`)  
- Логика доступности добычи по глубине и напряжённости поля  
- Поведение на граничных значениях глубины и напряжённости

---

## 2. Позитивные тест-кейсы

| ID | Название | Входные данные | Ожидаемый результат |
| ---- | ---------- | ---------------- | ---------------------- |
| PT-1 | Обнаружение на малой глубине | `depth_cm = 5` | `detected = True`, `prey_type != ""`, `distance_mm >= 0` |
| PT-2 | Обнаружение на максимальной глубине (15 см) | `depth_cm = 15` | `detected = True` |
| PT-3 | Поле ≥1,8 мВ/см, но глубина чуть меньше 15 | `depth_cm = 14.9` | `detected = True` |
| PT-4 | Максимальное количество рецепторов (2000) → вероятность 1.0 | `electroreceptor_count = 2000` | вероятность обнаружения = 1.0 |
| PT-5 | Промежуточное кол-во рецепторов (например, 1000) | `electroreceptor_count = 1000` | вероятность = 0.5 |
| PT-6 | Добыча реально существует (симуляция поля) | `depth_cm = 10`, поле ≥1,8 | `detected = True`, `prey_type` определён |

---

## 3. Негативные тест-кейсы

| ID | Название | Входные данные | Ожидаемый результат |
| ---- | ---------- | ---------------- | ---------------------- |
| NT-1 | Глубина больше 15 см | `depth_cm = 16` | `detected = False` |
| NT-2 | Глубина намного больше | `depth_cm = 50` | `detected = False` |
| NT-3 | Напряжённость поля ниже порога (1,79 мВ/см) | поле < 1,8 (моделируется) | `detected = False` |
| NT-4 | Электрорецепторов 0 штук | `electroreceptor_count = 0` | вероятность = 0 → `detected = False` |
| NT-5 | Отрицательная глубина | `depth_cm = -5` | `detected = False` (или обработка ошибки, см. граничные случаи) |
| NT-6 | Добычи нет (поле = 0) | поле = 0 | `detected = False` |

---

## 4. Граничные тест-кейсы

| ID | Название | Входные данные | Ожидаемый результат |
| ---- | ---------- | ---------------- | ---------------------- |
| BT-1 | Глубина ровно 15 см | `depth_cm = 15` | `detected = True` |
| BT-2 | Глубина 15.001 см | `depth_cm = 15.001` | `detected = False` |
| BT-3 | Напряжённость ровно 1,8 мВ/см | поле = 1.8 | `detected = True` |
| BT-4 | Напряжённость 1,799 мВ/см | поле = 1.799 | `detected = False` |
| BT-5 | Глубина 0 см | `depth_cm = 0` | `detected = True` (если поле ≥1,8) |
| BT-6 | Рецепторов 1999 | `count = 1999` | вероятность = 0.9995 → `detected` зависит от поля |
| BT-7 | Рецепторов 2001 | `count = 2001` | вероятность = 1.0 (`min` сработал) |
| BT-8 | Глубина None / не число | `depth_cm = None` | ошибка или `detected = False` (строгая типизация) |

---

## 5. Дополнительные проверки

| Тип проверки | Описание |
| --------------- | ----------- |
| Тип возвращаемого значения | Всегда `dict` с тремя ключами |
| Тип `detected` | `bool` |
| Тип `prey_type` | `str` (при `detected=False` может быть пустой строкой или `"none"`) |
| Тип `distance_mm` | `float` (при `detected=False` может быть `0.0` или `-1.0`) |
| Воспроизводимость | При одинаковых входных данных и рецепторах результат детерминирован |
| Границы вероятности | Не выше 1.0 и не ниже 0.0 |
